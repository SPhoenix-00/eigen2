# ROCm Requirements for Project Eigen 2
# =====================================
#
# This file contains dependencies for AMD GPU (ROCm) support.
#
# IMPORTANT: For Runpod/Docker deployments with pre-installed ROCm PyTorch:
#   - The base image (e.g., runpod/pytorch:2.4.0-py3.10-rocm6.1.0-ubuntu22.04)
#     already has PyTorch with ROCm support installed.
#   - DO NOT run: pip install -r requirements_rocm.txt (it will overwrite PyTorch!)
#   - Instead run: pip install -r requirements_rocm_no_torch.txt
#
# For bare-metal installations:
#   1. Install ROCm drivers from: https://rocm.docs.amd.com/
#   2. Upgrade pip: python -m pip install --upgrade pip
#   3. Install all dependencies including PyTorch:
#      python -m pip install -r requirements_rocm.txt
#
# Supported AMD GPUs:
#   - Consumer: RX 6800, 6900 XT, 7900 XT, 7900 XTX (RDNA2/RDNA3)
#   - Datacenter: MI100, MI200, MI250, MI300 series
#
# Recommended ROCm versions: 6.0 or later

# -------------------
# 1. The torch.cuda.* API works identically on ROCm
# 2. No code changes needed - just different PyTorch wheel
# 3. Environment variables are set automatically by utils/device.py:
#    - PYTORCH_HIP_ALLOC_CONF=expandable_segments:True
#    - HSA_FORCE_FINE_GRAIN_PCIE=1
#
# Troubleshooting:
# ----------------
